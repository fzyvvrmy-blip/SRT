# KONIPONI 网页原型

这是一个纯前端、无后端依赖的可交互学生端原型。

## 打开方式

直接双击 `index.html`，或在该目录启动任意静态文件服务器后访问即可。

## 已搭建模块

- 首页：年级切换、四个功能入口、小马点击彩带与日语气泡。
- 单词：搜索建议与定位高亮、两种表格顺序、收藏、抽查记录和新建测试弹窗。
- 精读：点读/翻译开关、示意音频进度、原译文联动高亮。
- 资源：书架式资源占位及下载按钮。
- 个人中心：单词本搜索与删除；错题入口占位。
- 登录：仅学生端的示意登录页，可选择年级；作业：课次列表、单选/填空作答、提交结果与解析示意。

所有单词、课文、音频和下载资源均为可替换的 mock / 占位内容。首页会优先引用相邻 `网页原型我在这/飞书图片/06_home_horse.gif` 的小马素材；该素材缺失时自动显示字符占位。

可在地址后加哈希快速查看某页，例如 `index.html#login`、`index.html#words`、`index.html#reader`、`index.html#resources` 或 `index.html#homework`。
